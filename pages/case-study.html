Case Study

Building Airgead as a static financial calculator.

The goal was to keep the original compound interest logic useful while turning the experience into a polished GitHub Pages-ready demo.

The problem

The original project logic calculated investment growth, but a simple calculator form alone does not fully show the value of the project. A portfolio version needs to show the user flow, the comparison logic, the results, and the static-safe implementation.

The rebuild

This version separates the site into individual HTML pages, shared shell components, reusable calculator functions, page-specific scripts, and static assets. It keeps the same core logic while removing the need for React routing, server routes, a database, or a build step.

Client-side storage
Saved plans use localStorage so the demo can still feel app-like on GitHub Pages.
Export behavior
The CSV export is generated in the browser from the calculated year-by-year data.

Future enhancements

Airgead could eventually add account sync, goal tracking, inflation adjustment, multiple contribution schedules, PDF exports, and more detailed scenario modeling. For the portfolio demo, the important part is that the main financial logic works without pretending there is a backend.
