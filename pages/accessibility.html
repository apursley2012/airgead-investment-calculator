Accessibility features

Airgead uses semantic page structure, labeled form controls, visible keyboard focus, and a skip link to help people navigate with different input methods. Layouts adapt to smaller screens, and tables can be scrolled when necessary.

Charts are accompanied by explanatory text or numerical tables so readers can access important results without relying on color or chart shapes alone. The mobile navigation includes keyboard support.

Testing and known limitations

The project includes automated checks and selected browser interaction tests. These checks help identify problems but do not establish compliance with a particular accessibility standard.

A complete screen-reader review, formal accessibility audit, and testing across a broad range of physical devices have not been completed. Additional testing is needed before making a compliance claim.

Report an accessibility issue

If you encounter a barrier, describe the page, what you were trying to do, and the browser or assistive technology involved. That information helps identify and reproduce the issue.

Accessibility should be checked again whenever the layout, navigation, or interactive components change.
