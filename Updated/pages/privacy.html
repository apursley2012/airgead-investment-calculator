About this website

Airgead is a static educational investment calculator. The application does not operate real user accounts, process payments, or send investment inputs to an Airgead application server. This notice describes the behavior of the code included in this project.

The demo sign-in does not require a real password. Do not enter passwords or sensitive account information into the demonstration.

Data stored in your browser

The calculator uses browser localStorage to retain the current inputs and results so they can appear on the Results page. Saved plans also remain in localStorage, including their names, inputs, calculated figures, identifiers, and save dates.

The demonstration sign-in stores a temporary session indicator in sessionStorage. The application does not save the email address or password entered into the form, and the indicator does not provide authentication.

Browser storage is not secure account storage. Anyone with access to the same browser profile may be able to view saved plans, and clearing site data can remove them.

Downloads and third-party services

CSV files are generated locally in the browser and downloaded to your device. The application does not upload the export to an Airgead server.

The site loads Inter and Fraunces fonts from Google Fonts. Requests to Google’s font services may disclose technical information, including an IP address, under Google’s own privacy practices.

If the website is published through GitHub Pages or another hosting service, that provider may process network requests and server logs. Those practices are separate from Airgead’s browser-local calculations.

Storage, cookies, and your choices

The application does not include analytics scripts or set tracking cookies. Hosting providers and external font services may have their own logging or cookie practices.

Saved plans remain until you delete them or clear the site’s browser data. The demo session indicator is temporary. Clearing the site’s stored data also removes the current calculation.

Because the project has no server-side account database, it has no server-side account deletion process. If a future version adds analytics, authentication, or external storage, this notice must be updated.
